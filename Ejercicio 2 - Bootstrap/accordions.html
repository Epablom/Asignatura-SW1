Acordeones

Utilizan el plugin Collapse en JavaScript para permitir la construcción en vertical.

Primer elemento del cuerpo del acordeón. Se muestra por defecto (.accordion-button sin .collapsed y .accordion-body con .show), hasta que el plugin de colapse añade/elimina las clases apropiadas empleadas para dar estilo a cada elemento. Estas clases controlan la apariencia general, así como la visualización y ocultamiento a través de transiciones CSS. Se puede modificar cualquiera de estas con CSS personalizado o anulando las variables predeterminadas. También vale la pena mencionar que casi cualquier HTML puede ir dentro del .accordion-body, aunque la transición limita el desbordamiento.
